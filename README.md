## About

I'm interested in building practical, scalable applications and
exploring how AI can become a useful part of everyday workflows.

My current direction is focused on the intersection of:

-   **Full-stack development** --- building clean, maintainable web
    applications.
-   **AI-powered workflows** --- connecting multiple AI tools into
    practical systems.
-   **Personal software** --- creating tools that help organize
    information, plans, and execution.
-   **Continuous learning** --- experimenting, shipping, improving, and
    documenting along the way.

I value thoughtful engineering, clear documentation, and systems that
can evolve over time.

## What I'm Building

  -----------------------------------------------------------------------
  Project                             What it is
  ----------------------------------- -----------------------------------
  **Personal OS**                     A modular personal dashboard
                                      designed to bring plans, projects,
                                      and useful tools into one place.
